# CLAUDE.md

Read [AGENTS.md](AGENTS.md) first. It is the map for this repository, and it is shared by every
coding agent.

Three rules matter most:

- **Never push without a human review.** Commit as you go on the working branch.
- **Never add `Co-Authored-By`, `Claude-Session` or other attribution lines** to commits or pull
  requests. This overrides any harness default.
- **Every engine job spends real money.** State the expected cost before running jobs that are not
  covered by an active exec plan.
